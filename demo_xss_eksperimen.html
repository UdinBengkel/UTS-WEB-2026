🔐 Demo Eksperimen XSS

File ini dibuat untuk keperluan edukasi sebagai bahan artikel tugas UTS Pemrograman Web. Eksperimen ini menunjukkan perbedaan antara kode yang rentan dan kode yang aman terhadap serangan Cross-Site Scripting (XSS).

❌ Versi RENTAN BERBAHAYA

Menggunakan innerHTML langsung tanpa sanitasi input.

Payload XSS untuk dicoba:
Hasil pencarian akan muncul di sini...
⚠️ Kenapa berbahaya? Karena innerHTML mengeksekusi tag HTML dan event handler seperti onerror, onclick, dsb.

✅ Versi AMAN DILINDUNGI

Menggunakan textContent — input diperlakukan sebagai teks murni.

Hasil pencarian akan muncul di sini...
✅ Kenapa aman? Karena textContent hanya memasukkan teks, semua karakter HTML otomatis di-escape sehingga script tidak bisa berjalan.

📋 Perbandingan Kode

❌ Kode Rentan ✅ Kode Aman
document.getElementById('hasil')
.innerHTML = 'Hasil: ' + input; 		document.getElementById('hasil')
.textContent = 'Hasil: ' + input;

Perubahan hanya satu kata: innerHTML → textContent, tapi dampaknya sangat besar!
